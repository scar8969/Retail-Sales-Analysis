# Retail Sales Analysis 

## Problem
Analyze sales data to identify top products, cities, and trends.

## Features
- SQL-based analysis
- Excel insights
- Python data processing
- Interactive Streamlit dashboard

## Tech Stack
Python, Pandas, SQL, Excel, Streamlit

## Key Insights
- Laptop generates highest revenue
- Mumbai leads in sales
- Electronics dominate market

## Run Project
python -m streamlit run main.py
